# 🏔️ Mountain-OS: Kilimanjaro
A modern, high-performance desktop operating system custom-tailored for work, school, and daily productivity. Built on the rock-solid foundation of **Fedora KDE Kinoite** and the **Universal Blue** atomic framework.

---

## ✨ Features

*   **🍏 Premium Mac-Inspired Aesthetic:** Out of the box, Kilimanjaro boots into a clean, modern layout featuring a top global menu bar and a floating application dock at the bottom center.
*   **🪟 Instant Windows Option:** Prefer a traditional layout? Mountain-OS includes a built-in toggle engine. With one script click, the desktop interface instantly morphs into a familiar Windows taskbar and start menu arrangement.
*   **📚 Optimized for Work & School:** Built to provide exceptional laptop battery life, smooth trackpad gestures, and rock-solid system stability during heavy research tasks.
*   **📱 Deep Mobile Integration:** Powered natively by KDE Connect to seamlessly link your Android or iOS phone wirelessly to share files, reply to messages, and sync notifications instantly.

---

## 📦 Pre-Installed Essentials

Mountain-OS comes bundled with the precise applications you need to start being productive on day one, without any unnecessary bloatware:

*   **Firefox** – An ultra-secure, fast, and open-source web browser optimized for privacy.
*   **Okular** – A powerful document viewer for reading, highlighting, and annotating school textbooks or work PDFs.
*   **Kate** – A gorgeous, highly flexible modern text and code editor.
*   **Spectacle** – An advanced utility to record your screen or grab quick snapshots of lectures and meetings.
*   **Fastfetch** – A clean terminal utility to show off your custom system specifications.

---

## 💾 How to Install and Test

1. **Download the ISO Generator:** Because Mountain-OS is hosted as a secure cloud container registry image, you can use the official Universal Blue installer to generate a bootable ISO.
2. **Flash to a USB:** Open *Fedora Media Writer* or *Rufus* on your computer to write the installer to a spare flash drive.
3. **Disable Secure Boot:** Boot your computer into its motherboard UEFI settings and turn off Secure Boot.
4. **Launch the Installer:** Boot from your USB and follow the quick graphical setup wizard!
